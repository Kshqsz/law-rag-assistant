本毕业设计旨在设计并实现一个面向法律领域的智能问答系统，该系统基于检索增强生成（Retrieval-Augmented Generation, RAG）技术，融合本地法律知识库与互联网实时信息，利用大语言模型对用户提出的自然语言法律问题进行精准理解、知识检索与可靠回答。具体任务内容与要求如下：
  （1）技术要求。系统应采用主流 RAG 架构，集成开源大语言模型（如 Qwen 系列）作为生成模块；使用向量数据库（如 Chroma）存储本地法律条文的嵌入向量，支持高效语义检索；实现多源信息检索机制，在本地法规检索基础上，可调用 DuckDuckGo 等公开搜索引擎获取补充信息；设计合理的文档分块策略与选用适配的嵌入模型，确保法律文本在切分后仍保持语义完整性与检索准确性；通过提示工程（Prompt Engineering）约束大模型输出，确保生成答案引用明确法条、逻辑严谨、避免事实性幻觉；系统需具备良好的可解释性，能够清晰展示所依据的法律条文或检索来源。
（2）设计条件。开发环境应基于 Python 3.9 及以上版本，支持 LangChain 框架；本地法律知识库须覆盖《中华人民共和国民法典》《中华人民共和国刑法》《中华人民共和国民事诉讼法》等常用法律法规，并完成结构化处理；网络检索功能可使用开源工具或免费 API 实现；前端交互界面应采用轻量级 Web 框架开发；鼓励在国产软硬件生态下部署，优先选用阿里云 Qwen 等国产大语言模型，体现信创技术应用导向。
  （3）工作要求。学生须独立完成系统的需求分析、总体架构设计、核心模块开发与集成测试；实现一个功能完整、可运行的原型系统，支持用户以自然语言提问，并返回包含法条引用的结构化法律回答；撰写符合规范的毕业设计说明书，内容应涵盖课题背景与意义、相关关键技术综述、系统设计方案、实现过程、测试结果与分析等；按时提交完整的源代码、系统部署文档及演示视频，确保研究成果可复现、可验证。
